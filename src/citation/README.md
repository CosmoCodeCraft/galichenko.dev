# Citation styles

The bundled GOST R 7.0.5–2008, IEEE and APA 7 CSL files come from the [official Citation Style Language styles repository](https://github.com/citation-style-language/styles), version branch `v1.0.2`. Locale files come from the matching [CSL locales repository](https://github.com/citation-style-language/locales).

CSL styles and locales are distributed under CC BY-SA 3.0. Their embedded author and contributor metadata is preserved. They are processed locally at build time; publication pages make no runtime citation request.
